# Qarorlar

Muhim texnik va biznes qarorlar shu papkada — har biri alohida fayl: `NNN-qisqa-nom.md`
(masalan, `001-database-postgresql.md`). Maqsad — keyinchalik "nega shunday qildik?" savoliga javob topish.

## Format

```markdown
# NNN. Qaror sarlavhasi

- **Sana:** YYYY-MM-DD
- **Holat:** qabul qilingan | almashtirilgan (→ NNN)
- **Kontekst:** nima sababdan qaror kerak bo'ldi
- **Variantlar:** ko'rib chiqilgan alternativalar
- **Qaror:** nima tanlandi
- **Sabab:** nega aynan shu
- **Oqibat:** nimaga ta'sir qiladi, qanday risk bor
```
